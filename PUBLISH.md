# Как опубликовать сайт и подключить домен

Сайт — это папка с файлами. Мы кладём её на **GitHub Pages**: бесплатно, работает в России без VPN,
можно подключить свой домен. Папка `materials` в интернет не попадает (она исключена в `.gitignore`).

---

## Часть 1. Опубликовать сайт (≈15 минут, один раз)

### Шаг 1. Аккаунт на GitHub
1. Откройте https://github.com → **Sign up**.
2. Придумайте логин (он попадёт во временный адрес сайта, например `barkotey`), подтвердите почту.

### Шаг 2. Программа GitHub Desktop
Это приложение «загружает» папку сайта на GitHub без командной строки.
1. Скачайте с https://desktop.github.com и установите.
2. Откройте → **Sign in to GitHub.com** → войдите в свой аккаунт.

### Шаг 3. Загрузить папку сайта
1. В GitHub Desktop: меню **File → Add Local Repository…**
2. Нажмите **Choose…** и выберите папку `Документы/VibeCode 1` → **Add Repository**.
3. Нажмите синюю кнопку **Publish repository**.
4. Имя: например `site`. **Снимите галочку «Keep this code private»** (для бесплатного GitHub Pages репозиторий должен быть открытым — секретов там нет).
5. **Publish repository**.

### Шаг 4. Включить GitHub Pages
1. Откройте свой репозиторий на github.com (в GitHub Desktop: **Repository → View on GitHub**).
2. **Settings** (шестерёнка сверху) → слева **Pages**.
3. **Source:** `Deploy from a branch`. **Branch:** `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты вверху страницы появится адрес вида
   `https://ВАШ-ЛОГИН.github.io/site/` — это и есть ваш сайт.

### Шаг 5. Проверить
Откройте адрес на телефоне. Нажмите «Пригласить спикером» — должен открыться Telegram с готовым текстом заявки.

## Часть 2. Свой домен (например, barkovsky.ru)

### Шаг 1. Купить домен
- Регистраторы: reg.ru, nic.ru, timeweb.com и др. Домен `.ru` стоит примерно 200–900 ₽ в год.
- Проверьте свободные имена: `barkovsky.ru`, `barkotey.ru`, `barkology.ru`, `bark-psy.ru`…
- Для `.ru` регистратор попросит паспортные данные — это нормально.

### Шаг 2. Указать домен в GitHub
1. Репозиторий → **Settings → Pages → Custom domain** → впишите `barkovsky.ru` (ваш домен) → **Save**.
2. GitHub сам создаст в репозитории файл `CNAME`. В GitHub Desktop нажмите **Fetch origin → Pull origin**,
   чтобы этот файл появился и у вас на компьютере.

### Шаг 3. Настроить DNS у регистратора
В личном кабинете регистратора → ваш домен → **DNS-записи** (или «Управление зоной»). Добавьте:

| Тип   | Имя (хост) | Значение                |
|-------|------------|-------------------------|
| A     | @          | 185.199.108.153         |
| A     | @          | 185.199.109.153         |
| A     | @          | 185.199.110.153         |
| A     | @          | 185.199.111.153         |
| CNAME | www        | ВАШ-ЛОГИН.github.io     |

Старые A-записи для `@` (если регистратор поставил свои) — удалите.

### Шаг 4. Дождаться и включить HTTPS
1. Обычно домен начинает работать через 15–60 минут (иногда до 24 часов).
2. Вернитесь в **Settings → Pages** и поставьте галочку **Enforce HTTPS** (замочек в адресной строке).

### Шаг 5. Обновить превью ссылки
Попросите Claude: «поменяй og:image и og:url на мой домен barkovsky.ru» — тогда в Telegram и VK
у ссылки на сайт будет красивая карточка с фото.

---

## Как обновлять сайт потом
1. Попросите Claude изменить сайт — он внесёт правки и сделает коммит.
2. В GitHub Desktop нажмите **Push origin**.
3. Через 1–2 минуты изменения на сайте.

## Перед публикацией
- Покажите `privacy.html` юристу: если вы ИП или самозанятый, туда нужно дописать полное ФИО и ИНН.
  Юрист также подскажет, нужно ли уведомлять Роскомнадзор об обработке персональных данных.
