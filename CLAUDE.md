# CLAUDE.md — правила проекта «Сайт Алексея Барковского»

## О проекте
Сайт-визитка Алексея Барковского: психолог, спикер, бизнес-тренер, блогер, пишет книгу «Инструкция к жизни».
Аудитория: организаторы мероприятий, подписчики, слушатели. Большинство заходит с телефона.
Цель: за 10 секунд понять, кто он и о чём говорит → посмотреть видео → оставить заявку в Telegram / перейти в соцсети.

## Как общаться с владельцем сайта
- Владелец не программист. Объяснять по-русски, простыми словами, без жаргона.
- Перед крупными изменениями (новый раздел, смена дизайна, новые сервисы) — сначала коротко описать план и дождаться «да».
- После каждого готового блока — коммит в Git с понятным русским сообщением (например «Блок 3: темы лекций»).
- Тексты для сайта пишутся живым языком автора: прямо, с иронией, без воды и эзотерики. Источник тона — `materials/Обо мне.docx`.

## Технологии
- Только статичные файлы: HTML + CSS + немного JavaScript без библиотек. Никаких фреймворков, сборщиков, npm, сервера.
- Хостинг: GitHub Pages. Всё, что лежит в репозитории, публикуется.
  Репозиторий: https://github.com/Barkotey/barkotey.github.io (ветка `main`) → сайт https://barkotey.github.io/
  Владелец отправляет изменения сам: GitHub Desktop → **Push origin**.
- Локальный просмотр: `python3 -m http.server 8000` в папке проекта → http://localhost:8000.
  С телефона в той же Wi‑Fi сети: http://<IP-компьютера>:8000 (IP: `ipconfig getifaddr en0`).

## Дизайн-система
- Стиль: минимализм Apple. Почти чёрный фон, много воздуха, крупная типографика, плавное появление блоков.
- Цвета (переменные в `:root`):
  - фон `#050505`, текст белый;
  - серебряный градиент `#B4BEC4 → #80878B → #565B5E` — все заголовки (как надпись BARK в шапке, повторяется на каждой строке), рамки;
  - янтарный градиент `#D68401 → #C17600 → #855100 → #513200` — кнопки и главные акценты.
- Шрифты: заголовки — Coolvetica Compressed Heavy (`--font-display`), текст — Inter (`--font-text`),
  рукописные акценты/подписи — Shlapak Script (`--font-script`),
  акцентный — Soyuz Grotesk Bold (`--font-accent`): бегущая строка и номера лекций. Он «однорегистровый»:
  заглавные и строчные выглядят одинаково (т как m, л как Λ) — это задумка шрифта, не ошибка.
- Рукописная пометка блока (`.eyebrow`) — как подпись от руки: небольшая, чуть наклонена, начинается у левого края
  заголовка и НЕ заходит на другой текст. Заголовки блоков — по центру.
  Рукописные подзаголовки в «Обо мне» (`.zone__label`: Сцена, История, Призвание, Опыт) — крупные, по центру, наезжают на фото.
- Shlapak Script в `assets/fonts/shlapak-script.woff2` доработан: строчная «т» нарисована как рукописная «m»
  (родная перечёркивала соседние буквы длинной чертой), кавычки „ “ собраны из двух штрихов (родные — крошечные).
  «Ёлочек» «» в шрифте нет — в рукописных надписях писать „Так“. Заглавные «Г» и «П» у шрифта странные — лучше избегать.
  У «р», «д», «у», «з» очень длинные хвосты вниз: под рукописными надписями оставлен отступ,
  а подзаголовку со «з» или «у» добавлять класс `zone__label--deep`.
- Фон не пустой: пятна света `.glow` (янтарные/серебряные), плёночное зерно, коты-водяные знаки `.watermark`,
  бегущая строка `.ticker`, фото-вставка `.interlude`. Отступы между блоками — умеренные (`--section-pad`).
- Подвал — огромная надпись BARK во всю ширину контейнера. Владельцу нравится именно крупно — не уменьшать.
- Логотипы (векторные, вырезаны из гайдлайна `materials/figma/BARK Design.pdf`):
  `cat.svg` — кот в профиль (ЕДИНСТВЕННЫЙ кот на сайте, кота анфас не использовать), `bark.svg` (надпись BARK),
  `monogram.svg` (монограмма «АБ»), `signature.svg` (подпись). Красятся через CSS `mask` + градиент (класс `.mark`).
- Новые цвета не придумывать — брать из переменных. Если очень нужно — добавить переменную в `:root`.

## Правила вёрстки
- Mobile-first: сначала телефон (375–430 px), потом `@media (min-width: …)` для планшета/компьютера.
- Никакой горизонтальной прокрутки. Боковой отступ на телефоне — `--gutter` (20px).
- Кнопки и ссылки — не меньше 44×44 px для пальца.
- Анимации уважают `prefers-reduced-motion`. Без JavaScript весь контент всё равно виден.
- Анимации от прокрутки «как у Apple»: элементу ставится `data-scroll`, `main.js` даёт ему переменную `--p` (0…1),
  а масштаб/поворот/сдвиг считаются в CSS через `var(--p)`. `data-scroll="top"` — для первого экрана,
  `data-scroll="words"` — текст «загорается» по словам. Сейчас так работают: первый экран, текст «Обо мне»,
  стопка лекций (телефон), бегущая строка, фото-вставка, 3D-книга, iPhone в контактах, пятна света.
- Каждый `<img>`: `width`/`height`, осмысленный `alt` на русском, `loading="lazy"` (кроме первого экрана).

## Фото
- Оригиналы — в `materials/`. На сайт — уменьшенные копии в `assets/img/`:

- Цель: одно фото ≤ 300 КБ.

## Заявки в Telegram
- Любая ссылка с атрибутом `data-invite` становится ссылкой «написать в Telegram с готовым шаблоном заявки».
  `data-invite="Название лекции"` — тема подставится в шаблон. Логин Telegram и текст шаблона — в начале `assets/js/main.js`.

## Как пополнять
- **Отзыв** (скриншот переписки): исходник владелец кладёт в `materials/` как `review N.jpg`. Обрезать до «пузыря» сообщения,
  уменьшить до 900 px в ширину → `assets/img/reviews/review-N.jpg`. В `index.html` (блок `#reviews`) скопировать строку `<li>`
  в `<ul class="reviews__track">`, поменять номер, width/height и `alt` (в alt — полный текст отзыва). Лента сама станет длиннее.
- **Видео VK:** в блоке `#video` вставить адрес плеера (`https://vk.com/video_ext.php?oid=…&id=…&hash=…`) в `data-video=""`.
  Кнопка «Смотреть лекцию» станет активной; плеер VK грузится только по нажатию.
- **Продукт (позже):** карточка `.product-card` — тот же шаблон, что у тизеров в блоке `#book`; кнопка ведёт на внешний сервис оплаты.
- **Превью ссылки:** `og:image`/`og:url` в `index.html` — полные адреса на https://barkotey.github.io/. После подключения домена — заменить.

## Юридическое
- Сайт сам не собирает персональные данные (заявки уходят в Telegram). Если появятся формы, аналитика
  (например, Яндекс Метрика) или оплата — обновить `privacy.html` и сказать владельцу.
- Не подключать сторонние сервисы, которые передают данные посетителей за рубеж (Google Fonts, Google Analytics и т.п.):
  шрифты хранятся локально.
