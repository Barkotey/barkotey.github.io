# CLAUDE.md — правила проекта «Сайт Алексея Барковского»

## О проекте
Сайт-визитка Алексея Барковского: психолог, коуч, лектор, блогер, пишет книгу.
Аудитория: организаторы мероприятий, подписчики, слушатели. Большинство заходит с телефона.
Цель: за 10 секунд понять, кто он и о чём говорит → посмотреть видео → оставить заявку в Telegram / перейти в соцсети.

## Как общаться с владельцем сайта
- Владелец не программист. Объяснять по-русски, простыми словами, без жаргона.
- Перед крупными изменениями (новый раздел, смена дизайна, новые сервисы) — сначала коротко описать план и дождаться «да».
- После каждого готового блока — коммит в Git с понятным русским сообщением (например «Блок 3: темы лекций»).
- Тексты для сайта пишутся живым языком автора: прямо, с иронией, без воды и эзотерики. Источник тона — `materials/Обо мне.docx`.

## Технологии
- Только статичные файлы: HTML + CSS + немного JavaScript без библиотек. Никаких фреймворков, сборщиков, npm, сервера.
- Хостинг: GitHub Pages. Всё, что лежит в репозитории, публикуется.
- Локальный просмотр: `python3 -m http.server 8000` в папке проекта → http://localhost:8000.
  С телефона в той же Wi‑Fi сети: http://<IP-компьютера>:8000 (IP: `ipconfig getifaddr en0`).

## Дизайн-система
- Стиль: минимализм Apple. Почти чёрный фон, много воздуха, крупная типографика, плавное появление блоков.
- Цвета (переменные в `:root`):
  - фон `#050505`, текст белый;
  - серебряный градиент `#B4BEC4 → #80878B → #565B5E` — заголовки, рамки, второстепенное;
  - янтарный градиент `#D68401 → #C17600 → #855100 → #513200` — кнопки и главные акценты.
- Шрифты: заголовки — Coolvetica Compressed Heavy (`--font-display`), текст — Inter (`--font-text`),
  рукописные акценты/подписи — Shlapak Script (`--font-script`).
- Логотипы (векторные, вырезаны из гайдлайна `materials/figma/BARK Design.pdf`):
  `cat-face.svg` (кот анфас), `cat-profile.svg` (кот в профиль), `bark.svg` (надпись BARK),
  `monogram.svg` (монограмма «АБ»), `signature.svg` (подпись). Красятся через CSS `mask` + градиент.
- Новые цвета не придумывать — брать из переменных. Если очень нужно — добавить переменную в `:root`.

## Правила вёрстки
- Mobile-first: сначала телефон (375–430 px), потом `@media (min-width: …)` для планшета/компьютера.
- Никакой горизонтальной прокрутки. Боковой отступ на телефоне — `--gutter` (20px).
- Кнопки и ссылки — не меньше 44×44 px для пальца.
- Анимации уважают `prefers-reduced-motion`. Без JavaScript весь контент всё равно виден.
- Каждый `<img>`: `width`/`height`, осмысленный `alt` на русском, `loading="lazy"` (кроме первого экрана).

## Фото
- Оригиналы — в `materials/`. На сайт — уменьшенные копии в `assets/img/`:
  `sips -Z 1600 -s format jpeg -s formatOptions 72 <исходник> --out assets/img/<имя>.jpg` (+ версия 800px для телефона).
- Цель: одно фото ≤ 300 КБ.

## Заявки в Telegram
- Любая ссылка с атрибутом `data-invite` становится ссылкой «написать в Telegram с готовым шаблоном заявки».
  `data-invite="Название лекции"` — тема подставится в шаблон. Логин Telegram и текст шаблона — в начале `assets/js/main.js`.
- Без JavaScript ссылка просто открывает чат https://t.me/barkotey.

## Как пополнять
- **Отзыв:** в `index.html` над блоком `#reviews` есть комментарий-шаблон: скопировать всё между `ШАБЛОН ↓` и `ШАБЛОН ↑`,
  вставить внутрь `<div class="reviews__list">`, заменить текст. Фото (необязательно) — в `assets/img/reviews/`, квадрат ~200×200.
  Пока нет ни одного отзыва, блок скрыт автоматически (CSS `:has`).
- **Видео VK:** в блоке `#video` заменить заглушку на `<iframe>` из VK Видео («Поделиться → Экспортировать → код для вставки»).
- **Продукт (позже):** карточка `.product-card` — тот же шаблон, что у тизеров в блоке `#soon`; кнопка ведёт на внешний сервис оплаты.

## Юридическое
- Сайт сам не собирает персональные данные (заявки уходят в Telegram). Если появятся формы, аналитика
  (например, Яндекс Метрика) или оплата — обновить `privacy.html` и сказать владельцу.
- Не подключать сторонние сервисы, которые передают данные посетителей за рубеж (Google Fonts, Google Analytics и т.п.):
  шрифты хранятся локально.
